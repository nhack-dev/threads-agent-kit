# 05 返信への返事

## 流れ
1. `python3 scripts/th_replies.py fetch --posts 10 --go`
2. `data/reply-drafts.json` の `reply` を書く（下の基準）
3. 持ち主に見せる（初めの2週間は全部）→ OK は `"approve": true`
4. `python3 scripts/th_replies.py send` → `send --go`

## 基準
| 返信の種類 | 返事 |
|---|---|
| 感想・共感 | お礼＋相手の言葉を1つ拾う（1〜2文） |
| 質問 | 短く答える。長くなるなら次の投稿のネタにして「近いうちに投稿でまとめます」 |
| 体験の共有 | 「◯◯なんですね」と受けて、1つだけ質問を返す（会話が続くと伸びやすい） |
| 批判 | 事実の誤りだけ1回丁寧に。言い返さない。迷ったら持ち主へ |
| 宣伝・荒らし | 返さない。持ち主の OK で `hide --go`（1段目の返信だけ非表示にできる） |

## やらないこと
- 全員に同じ文
- 1回に20件より多く
- 返事の中でのURLの連投
