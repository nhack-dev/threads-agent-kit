# 03 書き方の決まり

## 1行目
- 平らな言い切り（「〜です。」）より、気持ちや合図で始めるほうが読まれやすい傾向
  - 例（架空）：「正直、これ知ってたら3年早かった」「【報告】」「ちょっと聞いてほしい」
- 道具・サービスの話なら、ぼんやりした総称より **具体的な名前** を出す
- 1行目を文の途中（「〜で」「〜けど」）で切らない

## 本文
- 1本で完結するものは 100〜200字くらい・行は10行以内
- 「！」や「笑」で気持ちを出してよい（全体を同じ口調にしすぎない）
- 数字は持ち主の本当の数字だけ。「◯分で」「◯個」など手間の小ささを数字で
- 最後は問いかけ・続きへの「↓」・何も付けない、のどれか

## 書かないこと
- 1行目のURL（続きかプロフィールへ）
- 本文の #（Threads はトピック1つ。`- topic:` に書く）
- 「保存してね」「プロフ見てね」で毎回締める
- 「稼げる」「誰でも」「絶対」
- 「リプで配布」「いいねで受け取り」

## 確かめる
```
python3 scripts/th_post.py --file drafts/2026-11-01-0800.md
```
「注意」が出たら直す。「止めました」は必ず直す。

※ ここに書いた「傾向」は目安です。必ず自分のアカウントの数字（06）で確かめ、合わなければ `data/kata.md` に書いて変えてください。
