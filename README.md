# Threads エージェントキット

あなたの AI エージェント（Claude Code など）がこのフォルダを読むと、Threads の運用を毎日続けられるようになるキットです。

- 1日の投稿の型に沿って、その日の投稿を作る（1本・ツリー）
- 予約して、時刻が来たら投稿する
- 届いた返信に返事の下書きを作る（あなたが確かめたものだけ送る）
- 投稿の数字を取り、週に1回ふり返って型を育てる
- キーワードで投稿を探して、ネタと型を集める

**費用は、あなたが自分で取る Meta のアプリと、あなたの AI エージェントの利用料だけです。** Threads の API そのものは無料です。このキットはほかのサーバーに何も送りません。

---

## 最初の10分

1. このフォルダを自分のパソコンに置く（受け取ったリポジトリを clone する）
2. `python3 --version` で 3.11 以上か確かめる
3. `cp .env.example .env`
4. 下の「キーの取り方」で `TH_ACCESS_TOKEN` と `TH_USER_ID` を `.env` に入れる
5. つながるか見る：
   ```
   python3 scripts/th_whoami.py         # 送る予定のリクエストが出るだけ
   python3 scripts/th_whoami.py --go    # username が出れば成功
   ```
6. 試しに1本（まずは dry-run）：
   ```
   python3 scripts/th_post.py --file drafts/example.md
   ```
7. AI エージェントに「AGENT.md を読んで、今日の分をやって」と頼む

**投稿・返信は `--go` を付けたときだけ** 本当に送られます。

## キーの取り方

1. https://developers.facebook.com/ で「アプリを作成」→ ユースケースで「Threads API にアクセス」を選ぶ
2. 「権限」で次を足す（下の表）
3. 「アプリの役割」→ Threads テスターに自分の Threads アカウントを足し、Threads アプリの 設定 → アカウント → ウェブサイトのアクセス許可 → 招待 で承認する（アプリの表示名は変わることがあります）
4. トークンの作り方は2つ。どちらか：
   - **かんたん**：管理画面の「ユーザートークン生成ツール」で自分のアカウントのトークンを作る
   - **コマンド**：管理画面にリダイレクトURLを登録 → `.env` に `TH_APP_ID` `TH_APP_SECRET` `TH_REDIRECT_URI` → `python3 scripts/th_auth.py url` で出たURLを開く → 戻ってきたURLの `code=` を `python3 scripts/th_auth.py code <コード> --go`（長期トークン60日と user_id が出ます）
5. **60日で切れます。** 50日目くらいに `python3 scripts/th_auth.py refresh --go`（発行から24時間たっていれば延ばせる）

| 権限 | 使うところ |
|---|---|
| threads_basic | 全部に必要 |
| threads_content_publish | 投稿・ツリー |
| threads_manage_insights | 数字 |
| threads_read_replies | 返信を読む |
| threads_manage_replies | 返信する・非表示 |
| threads_keyword_search | キーワード検索（審査前は自分の投稿だけ出る） |

**自分のアカウント（テスター）だけに使うなら、アプリ審査は要りません。** 他人のアカウントで使う・検索で公開の投稿を出すには、権限ごとのアプリ審査が要ります。

## できること・できないこと（公式ドキュメントで確かめた範囲）

| やりたいこと | できるか | 道具 |
|---|---|---|
| テキスト・画像・動画・カルーセル（2〜20）の投稿 | できる | `th_post.py` |
| ツリー（自分の投稿に続きを付ける） | できる（`reply_to_id` でつなぐ） | `th_post.py` |
| トピック（1投稿に1つ） | できる | `th_post.py --topic` |
| 予約投稿 | API に予約の機能は無い → このキットが時刻を見て出す | `th_queue.py` |
| 投稿ごと・アカウントの数字 | できる（views と shares は公式で「開発中」） | `th_insights.py` |
| 返信を読む・返す・非表示 | できる（非表示は1段目の返信だけ） | `th_replies.py` |
| キーワード検索 | 審査前は自分の投稿だけ。審査後は公開の投稿 | `th_search.py` |
| DM | API に無い | ― |
| フォロー・いいねの自動化 | API に無い（やらない） | ― |

公式の上限：
- 1投稿 **500字**（絵文字はバイト数で数える）
- 24時間で **投稿250本・返信1000件・削除100件**（`threads_publishing_limit` で今の数が見られる）
- リンクは1投稿5つまで
- 画像：JPEG/PNG・8MB以下　動画：MOV/MP4・5分・1GB以下
- 画像・動画は **インターネットから見られるURL** に置く
- 作ってから公開まで **平均30秒** 待つのが公式のすすめ（このキットは既定で30秒待ちます）
- 検索は1人24時間で2200回まで

## 毎日の動かし方（cron の例）

```
# 5分おきに予約を見て出す
*/5 * * * * cd /path/to/threads-agent-kit && python3 scripts/th_queue.py run --go >> data/cron.log 2>&1
# 毎朝7時に数字
0 7 * * * cd /path/to/threads-agent-kit && python3 scripts/th_insights.py --limit 50 --go >> data/cron.log 2>&1
```

## 中身

```
README.md / AGENT.md / CLAUDE.md
playbooks/   1日の型・リサーチ・書き方・ツリー・返信・ふり返り
templates/   投稿の型集・1日の計画表・ふり返り・アカウントの軸
scripts/     API の道具（標準ライブラリだけ・既定は dry-run）
drafts/      下書き（1投稿1ファイル）
queue/       予約
data/        数字・ログ（git に入れない）
```

## 困ったとき

| 出たもの | 意味 | やること |
|---|---|---|
| エラーコード 190 | トークン切れ | 作り直す・延ばす |
| エラーコード 10 / 200番台 | 権限が無い | アプリの権限・テスターの承認を確かめる |
| ERROR / EXPIRED | 画像・動画が取れない／24時間公開しなかった | URL が開けるか・形式 |
| HTTP 429 | 呼びすぎ | 1時間あけて件数を減らす |
| `THREADS_API__LINK_LIMIT_EXCEEDED` | リンクが5つを超えた | 減らす |

## このキットは N-Hack のAIエージェント専用です

このキットは N-Hack の受講生さん専用のプレゼントです。**N-Hack のAIエージェント
（N-Hack のプラグインを入れた Claude Code など）が、このパソコンで動いていること**を
前提にしています。

- どのスクリプトも、最初に `scripts/nhack_gate.py`（門）を通ります。門は、このパソコンに
  N-Hack のAIエージェントの「印」があるかを**読むだけ**で確かめます（ネットにつなぎません・
  何も書き換えません・プラグインには一切触れません）。
- 印が足りない環境では、スクリプトは動かずに止まります（終了コード 2）。この環境でだけ
  動くのが正しい姿です。
- いま N-Hack 環境かどうかは、次のコマンドで確かめられます。

```bash
python3 scripts/nhack_gate.py
```

N-Hack 以外のパソコンにコピーしても動きません。受講生ページ・コンサルチャンネルの案内に
沿ってご利用ください。

分からない・動かない・時間がかかっている——そんなときは、ひとりで抱えないでください。
